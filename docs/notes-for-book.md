# 원고용 메모

- 숨김(`visible=false`)은 손님 화면 표시에서만 빼는 것이다. RLS는 `visible` 값과 무관하게 select를 전부 허용하므로, 공개 anon 키로 손님 화면과 똑같이 조회하면 숨긴 메뉴도 데이터로 내려온다. 원고에는 "숨김 = 손님 화면에서 빼기, 비밀 아님"이라고 명시할 것 — 가격·원가처럼 진짜 가려야 하는 값은 애초에 이 표에 넣지 않는다.
- 공유 Supabase 프로젝트에서 `auth.users` 에 직접 insert 하면 그 프로젝트에 물려 있는 다른 앱들의 트리거가 함께 실행될 수 있다(이번 작업에서 실제로 다른 앱 2개의 profile 행이 같이 생성됐고, 이후 정리함). 독자는 자기 프로젝트에서 이 과정을 따라 하므로 트리거 충돌이 없지만, 원고에는 "공유 프로젝트에 auth 사용자를 직접 insert하지 말 것"이라는 주의를 남긴다.
