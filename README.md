# 오후세시 커피 메뉴판 — 「사장님이 직접 만드는 디지털 메뉴판」 실습 예제

QR로 열리는 손님용 메뉴판과, 사장님이 로그인해 품절·가격·메뉴를 고치는 화면입니다. 설치 없이 HTML 파일로 동작합니다.

## 받는 법
1. 이 페이지 위쪽 초록색 **Code** 버튼 → **Download ZIP**
2. 압축을 풀고 `index.html` 을 더블클릭하면 메뉴판이 열립니다 (처음에는 `menu-backup.js` 의 메뉴가 보입니다)
3. 책 순서대로 따라 하고, 막히면 `steps/` 와 비교하세요

## 파일
| 파일 | 내용 |
|---|---|
| index.html | 손님 화면 |
| admin/ | 사장님 화면 |
| config.js | Supabase 주소와 공개 키를 넣는 곳 |
| menu-backup.js | 첫 10분용 메뉴 + DB가 멈췄을 때 보여 줄 비상용 메뉴 |
| supabase/ | 표·보안 규칙 SQL, 사장님 등록 SQL, PIN 시연 SQL(운영 금지) |
| tools/ | 메뉴 한 번에 올리기, 보안 점검, PIN 시연 |
| qr/ | QR 카드 인쇄(A6) |
| prompts.md | AI 지시문 모음 |

## 꼭 지킬 것
- `config.js` 에는 **공개 키(publishable 또는 anon)만** 넣습니다. 비밀 키(secret, service_role)를 넣으면 누구나 메뉴판 DB를 마음대로 바꿀 수 있습니다. 실수로 넣었다면 Supabase에서 그 키를 바로 폐기하세요.
- 배포한 뒤 `tools/security-check.html` 로 "통과"가 나오는지 확인하세요.

## 사용 조건
- 「사장님이 직접 만드는 디지털 메뉴판」 구매자는 이 저장소의 코드를 자기 가게·자기 프로젝트(개인·상업 모두)에 자유롭게 쓰고 고칠 수 있습니다.
- 저장소 내용이나 책을 그대로, 또는 다른 자료와 묶어서 다시 파는 것(재판매)과 재배포는 안 됩니다.
- 사진은 실습용으로 AI가 생성한 이미지입니다. 가게 이름·주소는 모두 가상입니다.
